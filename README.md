# KinoUA (демо) · версія 4.1

Статичний сайт без збірки й залежностей. Інтерфейс: українська (типова), русский, English. Теми: темна, світла, авто.

## Запуск
- Локально: `python3 tools/serve.py` → http://localhost:8765 (сервер підтримує HTTP Range — без цього не працює перемотування відео).
- **Не відкривайте `index.html` подвійним кліком (file://).** Сторінки працюють, але YouTube не вбудовує трейлери без адреси сайту
  (помилка 153 «Помилка конфігурації відеопрогравача»). Сайт це розпізнає й пропонує відкрити трейлер на YouTube.
- GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.

## Сторінки
| Сторінка | Що там |
|---|---|
| `index.html` | Банер «у списку TMDB Popular», плеєр із подвійними субтитрами (демо-сцена), 100 фільмів, 30 мультфільмів, 10 серіалів, нові прем’єри, можливості, демо-ролик, FAQ |
| `catalog.html?type=…&genre=…&year=…&ol=…&lvl=…&q=…&sort=…` | Каталог. Фільтри діють разом: розділ, жанр, рік, **мова оригіналу** (`ol`, код ISO 639-1), **рівень CEFR** (`lvl`, кілька через кому, `unk` = не визначено), назва. Сортування: `pop` (TMDB Popular), `sn`, `sr` (IMDb), `srt` (TMDB), `st`, `sy`, `rec` |
| `movie.html?id=<slug>[&s=<сезон>&e=<серія>]` | Один шаблон для фільмів, мультфільмів і серіалів: оцінки IMDb і TMDB окремо, перехід на IMDb, мова й рівень, трейлер, актори, сезони |
| `search.html?q=…` | Пошук за оригінальною, українською й російською назвою |
| `profile.html` | Вхід через Google (Supabase Auth), налаштування, обране, історія, словник |
| `watch.html` | Лише переадресація старих посилань на `movie.html` (повного перегляду фільмів немає) |

## Структура
- `js/data.js` — жанри; `js/catalog.js` — легкий індекс 140 тайтлів; `data/titles/<slug>.js` — подробиці (опис, актори, сезони, серії).
- `js/nav.js` — шапка, картка (значки мови оригіналу й рівня, підписане джерело оцінки), стрічки, кнопка «нагору».
- `js/player.js` — плеєр KinoUA з кількома рядками субтитрів; **трейлери YouTube** (`K.yt`, `K.trailer`).
- `js/app.js` — каталог, пошук, сторінка тайтлу; `js/home.js` — головна; `js/profile.js` — профіль; `js/theme.js` — теми.
- `js/i18n.js` — **згенерований** файл словників (uk / ru / en). Джерела — `tools/i18n/*.json|*.py`, збірка: `python3 tools/i18n/build.py .`
- `tools/cefr.py` — приблизна оцінка рівня CEFR за транскриптом; `tools/video-studio.html` — генератор демо-відео; `tools/serve.py` — локальний сервер.

Після змін у JS/CSS збільшіть `?v=` у `*.html` і `KUA_VER` у `js/config.js`.

## Дані
- **TMDB** (знімок 18.10.2026): назви, описи, дати, жанри, актори, постери, кадри, `original_language` (поле `ol`), оцінка TMDB, позиція в «Popular» (`pop`).
- **IMDb ID** (`imdb`, напр. `tt0245429`): 135 тайтлів — з Wikidata (властивість P345 для відповідного TMDB ID), 5 нових фільмів, яких ще немає у Wikidata, —
  за точним збігом назви, року й двох акторів. Кожен ID звірено з IMDb (назва + рік). Посилання формується лише з перевіреного ID.
- **Оцінка IMDb** (137 тайтлів, із кількістю голосів): з офіційного набору [IMDb Non-Commercial Datasets](https://developer.imdb.com/non-commercial-datasets/)
  `title.ratings.tsv.gz` від 19.10.2026. Ліцензія — лише для особистого й некомерційного використання; для комерційного запуску потрібна ліцензія IMDb.
  Відгуки IMDb на сайт не завантажуються — є посилання «Відгуки й оцінки на IMDb».
- IMDb і TMDB зберігаються окремими записами в `ratings` (`src:"IMDb"` / `src:"TMDB"`) і ніде не змішуються.
- Повного перегляду фільмів немає: ліцензованого джерела відео поки немає. Демонстраційні фільми Blender Foundation з каталогу видалено.

## Рівень мови (CEFR)
- Поле `lvl` = `{v:"B1", approx:true, method, basis}` або `null` («Рівень не визначено»). Фільтр і значки показують лише визначені рівні.
- Оцінка можлива тільки за транскриптом (субтитрами). Для 140 тайтлів каталогу легального джерела транскриптів зараз немає, тому їхній рівень **не визначено** —
  ми не вгадуємо. Для демо-сцени «Маяк» рівень пораховано: ≈ B1 (мала вибірка).
- Як додати: отримайте англійські субтитри, на які маєте права (.srt/.vtt), і виконайте `python3 tools/cefr.py --json файл.srt`,
  потім впишіть результат у поле `lvl` тайтлу в `js/catalog.js`. Метод: лексика поза 3000/8000 найуживаніших слів, довжина речень, темп (слів/хв),
  ідіоми й фразові дієслова, складна граматика. Чіткість вимови з тексту не оцінюється. Це приблизна оцінка, не сертифікат CEFR.
  Частотний список (Google Web Trillion Word Corpus, 20 000 слів) завантажується в `tools/.cache/` при першому запуску; для комерційного використання замініть його ліцензованим.

## Трейлери
- Офіційний IFrame Player API YouTube (`youtube-nocookie.com`), запуск лише після натискання, стандартні елементи керування.
  Закриття вікна зупиняє й вивантажує відео, повертає прокрутку й фокус.
- **Причина помилки 153:** YouTube не отримав адресу сторінки (HTTP Referer). Так буває на `file://` або коли сервер віддає `Referrer-Policy: no-referrer`.
  Виправлено: `<meta name="referrer" content="strict-origin-when-cross-origin">` на всіх сторінках, `origin`/`widget_referrer` у плеєрі, окреме повідомлення для `file://`.
- Якщо ролик не можна вбудувати (помилки 2/5/100/101/150/153) або плеєр не відповідає 15 с — показується пояснення й кнопка «Відкрити на YouTube», без нескінченного завантаження.
- 136 трейлерів перевірено (oEmbed, 19.10.2026). У 4 тайтлів трейлера немає — кнопка неактивна з поясненням. Власник ролика може змінити дозволи будь-коли.

## Подвійні субтитри й демо-відео
- **Плеєр KinoUA** показує одночасно будь-яке поєднання українська / русский / English (порядок uk → ru → en), з розміром, положенням і фоном.
- **Демо-сцена «Маяк»** (24 с) і **демо-ролик** (50 с) створені програмно в `tools/video-studio.html` (canvas + WebCodecs + `tools/vendor/mp4-muxer.js`, MIT),
  репліки — синтез мовлення macOS. У ролику показано справжні тайтли каталогу з підписом «Трейлер · опис» і демо-сцену як єдиний повний плеєр.
- Вбудований плеєр YouTube показує лише одну мову субтитрів.

## Налаштування (`js/config.js`)
- `supabase.url` і `supabase.publishableKey` — **публічні** значення проєкту Supabase для входу через Google. Поки порожні — кнопка Google неактивна з поясненням.
- `supportTelegramUrl` — посилання на чат підтримки. Поки порожнє — «Підтримка в Telegram · скоро».
- `auth.emailEndpoint`, `auth.telegramStartUrl` — майбутні серверні маршрути. Порожнє = спосіб вимкнено («Скоро»).

## Вхід через Google (Supabase Auth)
- `profile.html` підключає офіційний SDK `@supabase/supabase-js@2.117.2` з jsDelivr (версія зафіксована, перевірка цілісності SRI), потім `js/auth.js` — **один** клієнт на сторінку.
- Потік PKCE: кнопка → `signInWithOAuth({provider:"google", options:{redirectTo}})` → Google → Supabase → `…/kinoUA/profile.html?code=…`.
  SDK сам обмінює `code` на сесію (`detectSessionInUrl`), після цього службові параметри прибираються з адреси.
- «Ввійшли» показується лише після перевірки сесії на сервері (`auth.getUser()`), не за параметрами в адресі. Сесію зберігає й оновлює SDK; після перезавантаження вона відновлюється.
- Вихід — `auth.signOut()`. Помилки OAuth (скасування, мережа, відповідь сервера) показуються мовою інтерфейсу.
- У браузер можна класти лише Project URL і publishable/anon key. `service_role`/secret key і Google Client Secret — ніколи (сайт відмовиться запускати вхід, якщо побачить секретний ключ).

### Що налаштувати вручну
1. **Supabase → Project Settings → API Keys**: скопіюйте *Project URL* і *Publishable key* (або legacy *anon*) у `js/config.js`.
2. **Supabase → Authentication → URL Configuration**: Site URL `https://saudade165.github.io/kinoUA/`; Redirect URLs `https://saudade165.github.io/kinoUA/**`
   (або точна адреса `https://saudade165.github.io/kinoUA/profile.html`). Для локальної перевірки можна додати `http://localhost:8765/profile.html`.
3. **Supabase → Authentication → Sign In / Providers → Google**: увімкнено, заповнені *Client ID* і *Client Secret* з Google Cloud; скопіюйте звідти *Callback URL* (`https://<id-проєкту>.supabase.co/auth/v1/callback`).
4. **Google Cloud Console → APIs & Services → Credentials → OAuth client (Web application)**: Authorized JavaScript origins `https://saudade165.github.io`;
   Authorized redirect URIs — саме *Callback URL* із кроку 3 (адреса Supabase, а не адреса сайту). Екран згоди OAuth має бути налаштований (у режимі Testing — додайте тестових користувачів).

### Майбутня синхронізація даних
Обране, історія, словник і налаштування поки зберігаються лише в браузері. Шаблон таблиць із Row Level Security (кожен бачить лише свої рядки) — `supabase/rls-template.sql`; зараз він не виконаний.

## Інші способи входу
Telegram і email вимкнені з підписом «Скоро»: для них немає серверної частини. Сайт не імітує надсилання листів чи вхід.
